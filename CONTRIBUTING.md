# Contributing to Code View

Bug reports, documentation improvements, tests, and code contributions are welcome.
Use this repository's GitHub Issues and Pull Requests. For bugs, include macOS
version, tool versions, reproduction steps, and a small non-sensitive Python
example. Remove source code and session tokens from logs before sharing.

Fork the repository and create a branch from main. Follow
[the development guide](docs/TECHNICAL.md#17-build-and-verification), add a regression
test and eval for behavior changes, and run the documented gate and eval checks.
Submit a focused pull request explaining the problem, behavior, and verification.
Do not commit dependencies, build outputs, credentials, or private repositories.

Contributions are accepted under the project's GNU GPL version 3 license.
Preserve inherited copyright and third-party notices. See [NOTICE.md](NOTICE.md).
